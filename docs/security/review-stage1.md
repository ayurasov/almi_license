## 3. Секреты в журналах, исключениях, ответах, дампах

- **Сервер.**
  - Журналы — строки JSON (`infra/logs.py`): текст исключения не пишется, только его тип.
  - В журналы не попадают ключ лицензии (хранится хэш и маска), аренда, подпись и `nonce`. Проверено сценарием 14 на журнале стенда.
  - Ответы problem+json не содержат внутренних данных.
  - В настройках `dev` Django дополнительно выводит трассировки в консоль. В `prod` используется только JSON-формат.
- **Ключи на сервере.**
  - Ключ выпуска и ключ локального сервера — файлы с правами 0600, в образ не входят.
  - Пароли БД — секреты Docker.
  - `seed_load` пишет закрытые ключи устройств только на стенде, файл удаляется после прогона.
- **DL.**
  - `LM_GetLastError` возвращает только `user_message`.
  - Исключения перехватываются на границе C ABI и становятся `LM_ERR_INTERNAL`.
  - Ключ устройства и полезная нагрузка аренды лежат в `SecureBytes` с `sodium_memzero`.
  - Не сделано: `sodium_mlock` и исключение страниц из дампа (`MADV_DONTDUMP` или аналог Windows) — см. замечание 5.

## 4. DL: повреждённое хранилище, диск, права, буферы

| Ситуация | Поведение | Проверка |
|---|---|---|
| Хранилище повреждено или перенесено с другой машины | Создаётся новое; `LM_Initialize[Ex]` → `LM_ERR_STORE_CORRUPTED`; событие `store_corrupted` уходит на сервер | `SecureStoreTest.DamagedTruncatedOrForeignFilesAreCorrupted`, `Abi.CorruptedStoreIsReportedOnceAndReset` |
| Диск недоступен или запись не удалась | Атомарная запись (временный файл, `fsync`, `rename`); при ошибке остаётся прежнее содержимое | `SecureStoreTest.ReplacementIsAtomic` |
| Нет прав на системный каталог меток | Метка пишется в пользовательский каталог | `TrialTrackerPlace.MarkDirectoryFallsBackWhenThePreferredOneIsNotWritable` |
| Буферы `LM_*` | Длина проверяется до записи; короткий буфер → `LM_ERR_BUFFER_TOO_SMALL`, буфер не изменяется; `struct_size` проверяется | `GetVersion.*`, `Abi.InitializeExGivesATrialWithoutAServer`, ASan/UBSan в CI |
