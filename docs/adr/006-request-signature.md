# ADR-006. Подпись запросов ключом устройства

- Статус: принято (Р6, раздел 5 документа 1)
- Дата: 23.10.2026
- История: E00-08

## Контекст
Токен в заголовке можно перехватить и продлить чужую активацию; общий секрет между сервером и продуктом противоречит принципу 5.

## Решение
Продукт создаёт пару Ed25519 устройства при активации, открытый ключ регистрируется в `Activation.device_pubkey`. Каждый запрос Product API подписан: заголовок `ALMI-Signature`, строка `ALMI-REQ-V1\n<METHOD>\n<path>\n<created>\n<nonce>\n<sha256 тела>` (раздел 4.4 документа 2); окно ±300 с, уникальность `nonce` в окне 600 с.

## Последствия
Знание `activation_id` не даёт продлить активацию. Отпечаток ключа устройства (RFC 7638) входит в аренду, поэтому аренда не переносится на другое устройство. Векторы — `contracts/vectors/request-signature`.
