# ADR-010. Vue 3 для консоли

- Статус: принято (Р10, раздел 5 документа 1)
- Дата: 23.10.2026
- История: E00-08

## Контекст
Консоль оператора не зависит от ЛК; переиспользование кода ЛК не требуется; важна доступность специалистов.

## Решение
Консоль — Vue 3.5, TypeScript strict, Vite, PrimeVue 4, Pinia, Vue Router, vue-i18n (`console/`). Клиент API генерируется из OpenAPI и руками не правится; тексты — только через i18n.

## Последствия
Каркас и эталонный экран — I2-07; остальные экраны строятся по образцу эталонного (I3-01).
