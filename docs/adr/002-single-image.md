# ADR-002. Один образ для центрального и локального сервера

- Статус: принято (Р2, раздел 5 документа 1)
- Дата: 23.10.2026
- История: E00-08

## Контекст
Закрытые контуры заказчиков требуют локального сервера лицензирования; отдельный продукт удвоил бы код и тестирование, а поведение разошлось бы.

## Решение
Один образ `deploy/Dockerfile` (`runtime`), режим задаётся `DEPLOYMENT_MODE=central|local`; проверка значения — при старте (`almi_license/settings`). Отличия — конфигурация и источник прав: центральный выдаёт права, локальный получает их пакетом (`packages`).

## Последствия
Каждая функция сервера тестируется в обоих режимах там, где поведение различается; `make up` и `make up-local` поднимают оба режима. Эндпоинты, недоступные в режиме, отвечают ошибкой из каталога раздела 16 документа 2, а не отсутствуют в схеме.
