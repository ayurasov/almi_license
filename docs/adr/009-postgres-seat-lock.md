# ADR-009. Учёт мест в PostgreSQL с блокировкой строки лицензии

- Статус: принято (Р9, раздел 5 документа 1)
- Дата: 23.10.2026
- История: E00-08

## Контекст
Счётчики в Redis требуют отдельного компонента и не дают транзакционной согласованности с активациями и аудитом.

## Решение
Любое изменение мест, лицензий и активаций выполняется в транзакции с `select_for_update` на строке `License`; занятые места считаются запросом в той же транзакции; резерв — `ceil(limit × reserve_pct / 100)`, место в резерве помечается `in_reserve` (раздел 7.4 документа 1). Событие аудита пишется в той же транзакции.

## Последствия
Двойное списание невозможно при любом числе параллельных запросов (тест E03-02: 50 параллельных активаций на limit=10, reserve_pct=3 → ровно 11 успешных). Активации одной лицензии сериализуются — приемлемо при ожидаемой нагрузке.
