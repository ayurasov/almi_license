# ADR-008. Адаптеры совместимости

- Статус: принято (Р8, раздел 5 документа 1)
- Дата: 23.10.2026
- История: E00-08

## Контекст
АльтерОфис Web (подписка через приложение Nextcloud) и АльтерОС (`registration.sh`) нельзя доработать к MVP.

## Решение
Модуль `compat` реализует существующие эндпоинты (`/apps/zammad_organisation_management/api/query/subscription/{key}`, `/api/activate/`) поверх доменных сервисов нового сервера. Форма ответов — по фикстурам реальных запросов (E00-09).

## Последствия
Разбор входных данных `compat` — модуль с обязательным ревью. Без фикстур E00-09 адаптеры делаются вслепую (раздел 6 документа 3) — фикстуры перенесены в I2 как блокер E11-01/E11-03. Адаптеры удаляются после перевода продуктов на Product API.
