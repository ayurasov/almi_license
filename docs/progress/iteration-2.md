- CPP: E13-11 (`lm-demo`, заглушка) — модули I2-08 ещё не подключены к `LM_*` (E13-06, I3-04);
- QA: E16-01, E16-02 (стратегия, контрактные тесты QA); DO: E15-01, E15-02 (стенд `test-central`).

Демонстрация I2 (раздел 7 документа 10) в полном объёме не проводилась: `lm-demo activate` и стенд `test-central` отсутствуют. Показываемо: активация и проверка через API с подписью и аренды, проходящие `almi-keytool` и `LeaseVerifier` (`make cross-verify`); 50 параллельных активаций → 11 мест; вход в консоль и экран «Заказчики» (сценарий Playwright); предпросмотр синтетической выгрузки ЛК.

Технический долг: `next_check_at` без разброса; тексты сообщений только Desktop `commercial`; `restricted.feature` не отправляется; Admin API без своих кодов ошибок (вопрос 23); `customer_viewer` без доступа к своему заказчику; строки `nlohmann::json` в DL не обнуляются; `LM_ERR_STORE_CORRUPTED` нет в ABI (вопрос 26); очистка `nonce` и черновиков импорта — с очередью E12-01.

Решения для ADR: формат хранилища DL и ключ от `machine-id` (E13-05); сессии консоли и CSRF (E07-02); каталог ошибок Admin API (после вопроса 23).
