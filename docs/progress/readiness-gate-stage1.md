## 4. Известные ограничения выпуска

Для руководства оператора (`docs/user-guide.md`, раздел 17):

1. Отдельный ключ лицензии не отзывается — только вся лицензия.
2. Для АльтерОфис Web на этапе 1 превышение пользователей и окончание срока только показываются уведомлениями, ограничений нет.
3. Активации по телефону нет (этап 2).
4. Конкурентных мест и Integration API для ЛК нет (этап 2).
5. Без пакета доверия `GET /api/v1/trust` отвечает 503; продукты работают по встроенным корням.

Для команд продуктов (`docs/integration/product-guide.md`, `prototypes/README.md`):

1. Директивы `update_trust`, `show_message`, `set_server_url` модуль пока не выполняет, а сообщает о них как о неподдерживаемых. Смена сервера — через `LM_SetServerUrl` или конфигурацию.
2. Фоновая проверка по `next_check_at`, работа через системный прокси и с корпоративным корневым сертификатом, время старта ≤ 50 мс не подтверждены протоколом (чек-лист раздела 18, пункты 4, 18, 19). Нужен ручной тест на ВМ Windows и Astra/РЕД ОС.
3. Набора `tools/conformance` нет. Соответствие продукта подтверждается сценариями `prototypes/README.md` и E2E.
4. Освобождение места при деинсталляции выполняет установщик продукта (`LM_Deactivate`).
5. Сборки с `LM_TRUST_ROOTS=dev` (в том числе `mini-office`, `lm-demo`) принимают только аренды пробного сервера.
6. Форматы Nextcloud и `registration.sh` по предварительным фикстурам. До перевода в `enforce` их нужно сверить с реальными.

## 5. Проект решения

**Выпуск v1.0.0 разрешён с условиями.** Код, контракт по путям и методам, критерии 2–9, 11, 12, 14, 15 и план отката подтверждены. Ограничения не мешают работе в режиме `monitor`: продукты не ограничиваются, а отказы учитываются в статистике.

Условия до продуктивного развёртывания:

| № | Условие | Ответственный |
|---|---|---|
| У1 | Церемония ключей E17-04: продуктивный корень у двух ответственных; сертификат ключа выпуска продуктивного сервера; `TRUST_ROOTS` и `trust.json` | Технический лидер, руководитель проекта |
| У2 | Развёртывание по `docs/deployment.md`; cron копий и вынос копий с хоста; проверка «все профили `monitor`» | DevOps |
| У3 | Импорт выгрузки ЛК с протоколом сверки (число лицензий и мест по артикулам) | Оператор, FS2 |
| У4 | Решение по расхождениям контракта (`release-check-v1.0.0.md`, раздел 1): изменение контракта 1.2.0 или реализации | Руководитель проекта |
