- Тест подделки подписи в редких запусках не портил подпись (замена последних символов); теперь меняется один бит подписи.
- В CI покрытие `TrialTracker` упало ниже порога на раннере без прав root; учение копий не могло удалить свой каталог; `check.sh` комплекта падал на заполненном диске раннера. Исправлено в одном коммите (`530a729`).
- `pg_dump` с ошибкой давал «успешную» пустую копию (`sh` без `pipefail`); скрипты переведены на `bash` с `set -euo pipefail`.
