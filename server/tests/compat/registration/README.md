# Фикстуры адаптера `/api/activate/` (E11-03)

**Предварительные.** Построены по разделу 12.1 документа 2 и разделу 6 документа 5, а не записаны с текущего ЛК (E00-09, вопрос 16). Коды ответов и разметка HTML — предположение до записи реальных ответов `registration.sh`.

Формат: `request` — параметры (`query` для GET, `form` для POST), заголовок `Accept`; `response` — статус, `text` (текст HTML-страницы без разметки) или `json` (тело-образец: тест сравнивает состав полей и типы). Сравнение HTML — по извлечённому тексту и статусу, не побайтно.
