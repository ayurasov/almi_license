# Фикстуры адаптера подписки Nextcloud (E11-01)

**Предварительные.** Построены по разделу 11.1 документа 2, а не записаны с работающего приложения `support` (E00-09, вопрос 16). После записи реальных запросов и ответов файлы заменяются, тест `tests/compat/test_nextcloud.py` проверяет новый эталон без изменений кода теста.

Формат файла: `request` — путь, тело; `response` — статус и тело-образец. Тест сравнивает состав полей и типы значений, а не сами значения.
