# Оформление консоли «АЛицензия»

Консоль оформлена в стилистике продуктов АльтерОфис (АЭксперт, настройки АльтерОфис):
- красный акцент на нейтральных серых поверхностях;
- светлая боковая панель с группами разделов;
- белые панели со списками;
- статусы — «таблетки» с точкой.

## Имя и знак

- **Название:** «АЛицензия» — по образцу семейства «АТекст», «АТаблица», «АЭксперт»; подзаголовок — «Сервер лицензирования». Под меню подпись «АЛМИ · АльтерСофт». Тексты лежат в i18n (`app.*`) и меняются там же.
- **Знак** (`src/components/BrandMark.vue`, `public/favicon.svg`): красная скошенная плашка, как у приложений АльтерОфис, с белым ключом — образом сервера лицензий. Цвет плашки `#E41C1C`, как у знака АльтерОфис.
- **Логотип** (`src/components/BrandLogo.vue`): знак, название и подзаголовок. В боковой панели подзаголовок показывает режим сервера: «Центральный сервер» или «Локальный сервер».

## Цвета (`src/theme/preset.ts`)

| Токен | Значение | Где |
|---|---|---|
| `primary.500` | `#E41C1C` | Основные кнопки, активный пункт меню, ссылки, фокус |
| `primary.50` / `highlight` | `#FEF2F2` | Фон активного пункта меню, выделение, плитка «Требуют внимания» |
| `surface.50` | `#F7F7F8` | Фон боковой панели, заголовки таблиц |
| `surface.200` | `#E4E4E7` | Границы панелей и таблиц |
| `text` | `surface.800` / `surface.500` | Основной и приглушённый текст |
| Состояния | success / warn / danger | Активна, пробный период — зелёный; скоро истекает, отсрочка — янтарный; ограничена, заблокирована, отозвана — красный (`src/lib/states.ts`) |

Тёмная тема — тот же пресет с серыми поверхностями zinc. Переключатель в боковой панели, выбор запоминается в браузере (`localStorage`).

## Макет

- **Боковая панель** (`src/layouts/AppLayout.vue`).
  - Группы разделов в порядке работы оператора:
    - «Обзор»;
    - «Лицензирование»: заказчики, лицензии, активации, импорт;
    - «Справочники»: каталог, профили;
    - «Контроль»: статистика, журнал;
    - «Администрирование»: локальные серверы, пакет, пользователи.
  - Разделы, недоступные роли или режиму сервера, не показываются.
  - Панель сворачивается до значков.
  - Внизу — пользователь (инициалы, логин, роль) и действия: смена пароля, тема, свернуть меню, выход.
- **Страница раздела.**
  - Заголовок слева, основные действия справа (`.toolbar`).
  - Фильтры и таблица — на белой панели (`.panel`).
  - Кнопка «Найти» применяет фильтры, «Сбросить» появляется, когда фильтр задан.
- **Таблицы.**
  - Заголовки столбцов — серые, прописными.
  - Строка подсвечивается при наведении; строка лицензии открывает карточку.
  - Действия в строке — маленькие кнопки с контуром.
- **Карточка лицензии.**
  - Ссылка «← Лицензии», под ней заголовок — заказчик.
  - Подзаголовок: продукт, тип, статус и состояние.
  - Действия — кнопки с контуром и значками, «Команда продуктам» — основная.
  - Вкладки на панели; параметры — в две колонки.
- **Обзор** (`src/views/OverviewView.vue`, `src/lib/overview.ts`).
  - Плитки: лицензии, занятые места (с полосой), свободные места, «Требуют внимания» (отсрочка, ограничение, блок).
  - Таблица лицензий, истекающих в ближайшие 30 дней.
  - Распределение по состояниям.
  - Данные — из статистики (`GET /api/admin/stats`), своего API у экрана нет.
- **Вход, смена пароля, портал офлайн-активации.**
  - Вход: красная панель со знаком и назначением сервера, справа форма; со страницы входа есть ссылка на портал офлайн-активации.
  - Смена пароля и портал — логотип и форма на сером фоне.
  - Выбор файла — зона с пунктирной рамкой. Поле файла остаётся в странице для тестов и доступности.

## Правила

- Только компоненты PrimeVue и токены темы. Цвета в стилях — через CSS-переменные `--p-*`, своих HEX нет (исключение — знак и панель входа).
- Общие классы — в `src/styles/base.css`: `.toolbar`, `.panel`, `.filters`, `.row-actions`, `.dropzone`, `.muted`. Экран добавляет свои стили только для своего содержимого.
- Базовый размер шрифта — 14 px (`:root`), шрифт системный, внешних шрифтов и CDN нет.
- Все тексты — через i18n, в том числе подписи под значками (`title`, `aria-label`).
