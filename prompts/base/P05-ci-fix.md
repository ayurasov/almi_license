# P5. Исправление CI

```text
CI упал на задаче <имя задачи>. Вот журнал:
<вставить фрагмент журнала>

Найди первопричину, а не симптом. Запрещено: отключать проверки, снижать пороги покрытия, добавлять # noqa / # type: ignore / eslint-disable без объяснения в комментарии со ссылкой на историю, менять тесты так, чтобы они проверяли меньше.
Опиши причину в одном абзаце, исправь, запусти ту же проверку локально, сделай коммит fix(<модуль>): <причина> (<ID>).
```
