# P11. Разбор дефекта

```text
Дефект: <описание, шаги воспроизведения, ожидаемое и фактическое поведение, журнал, request_id>.
1. Напиши тест, который воспроизводит дефект и падает. Коммит test(<модуль>): reproduce <номер дефекта>.
2. Найди первопричину; объясни, почему существующие тесты её не поймали.
3. Исправь минимально. Коммит fix(<модуль>): <причина> (<номер дефекта>).
4. Предложи, какие ещё места могут иметь ту же ошибку, и проверь их.
```
