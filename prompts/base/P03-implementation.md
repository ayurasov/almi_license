# P3. Реализация

```text
Выполни шаги <2–…> плана: реализуй минимальный код, который проходит тесты <ID>.

Ограничения:
- бизнес-логика только в server/apps/<модуль>/domain/;
- время только через Clock, криптография только через CryptoProvider;
- изменения прав — в transaction.atomic с select_for_update на лицензии;
- событие аудита на каждое изменение прав;
- ошибки — доменные исключения, отображение в problem+json в api_product/errors.py.

После каждого шага: make lint и тесты затронутого модуля; коммит с сообщением из плана.
Не трогай файлы вне плана. Если без этого не обойтись — остановись и объясни почему.
```
