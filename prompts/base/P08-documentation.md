# P8. Документация

```text
Обнови документацию по истории <ID>:
- CHANGELOG.md: раздел Unreleased, одна строка на изменение поведения;
- docs/<руководство>: если меняется работа оператора, администратора или продукта;
- docstring доменных функций: что делает, исключения, инварианты.
Не переписывай документы целиком и не меняй docs/specs/. Коммит docs(<модуль>): <кратко> (<ID>).
```
