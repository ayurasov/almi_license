# P7. Ревью критичного модуля

Технический лидер использует вместе с чек-листом раздела 8 документа 6.

```text
Проверь diff модуля <signing / crypto / activation / policy / packages / audit / iam / compat / DL: …> по чек-листу:
<вставить строку чек-листа из раздела 8 документа 6 для этой области>

Для каждого пункта чек-листа: соблюдено / нарушено / не проверить по diff (что нужно посмотреть дополнительно).
Отдельно:
- построй сценарий атаки или гонки, который мог бы сломать этот код, и укажи, какой тест его закрывает; если теста нет — предложи тест;
- проверь сравнения секретов на постоянное время, порядок «проверка подписи → разбор полезной нагрузки», ограничение размера до разбора.
```
