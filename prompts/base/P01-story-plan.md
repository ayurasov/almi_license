# P1. План истории

```text
Составь план реализации истории <ID>. Пока без кода.

Формат:
1. Тесты: список тест-кейсов, по одному на каждый критерий приёмки и на каждый код ошибки; пути файлов тестов.
2. Изменения: файлы и что в каждом меняется; новые функции и их сигнатуры.
3. Шаги: 3–6 шагов, каждый заканчивается зелёными тестами и коммитом; сообщение коммита для каждого.
4. Риски: где можно нарушить правила AGENTS.md (транзакции, время, секреты, модульные границы).
5. Вопросы, без ответа на которые нельзя начинать.

Объём изменения — до 400 строк без тестов. Если больше — предложи разбить историю на части.
```

После ответа разработчик пишет: `План утверждён` или правки к плану.
