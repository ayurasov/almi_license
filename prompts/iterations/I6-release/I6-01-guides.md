# I6-01. Руководства (E17-01, E17-02)

```text
История <E17-01 | E17-02>. Напиши <руководство оператора | руководство по установке локального сервера> в docs/<user-guide.md | deployment.md>.

Источник — фактический код и консоль, а не docs/specs: пройди по маршрутам консоли (console/src/router), Admin API (/api/admin/schema), командам manage.py, скриптам deploy/. Где поведение расходится с docs/specs — выпиши расхождение отдельным списком в конце для технического лидера, в руководстве описывай фактическое поведение.
Структура: назначение и роли; <для оператора: ежедневные операции, лицензии, активации, импорт, профили и «прогрев», офлайн-запросы, локальные серверы, статистика, журнал; для администратора: требования, установка подключённого и изолированного сервера, регистрация, обмен пакетами и отчётами, резервное копирование и восстановление, обновление, проверка состояния, типовые неисправности>.
Для каждой операции: когда выполняется, шаги, результат, частые ошибки и что делать. Язык — простой, без внутренних терминов кода.
```
