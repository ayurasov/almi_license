# Итерации этапа 1

Для каждой итерации ниже указаны цель, входные условия, план по потокам, готовые промпты для ключевых историй, демонстрационный сценарий и критерии выхода. Готовый промпт итерации заменяет шаги P0–P1 базового цикла: в нём уже есть контекст и план. Шаги P2–P9 выполняются как обычно.

Истории без готового промпта выполняются по шаблону P0 с подстановкой строки из бэклога: она содержит критерии приёмки, исполнителя и ссылки на разделы.

Порядок внутри итерации: сначала истории критического пути (раздел 6 документа 3), затем остальные. В каждом потоке одновременно в работе не больше двух историй.
