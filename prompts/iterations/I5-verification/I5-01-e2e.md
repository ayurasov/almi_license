# I5-01. Сквозные сценарии (E16-04)

```text
История E16-04. Автоматизируй сквозные сценарии в tests/e2e/ (pytest + Playwright + lm-demo как клиент на ВМ Windows и Linux через SSH/WinRM).

Сценарии (каждый — отдельный тест с понятным именем и шагами в docstring):
1. Онлайн: активация → проверка → освобождение → повторная активация на другом устройстве.
2. Офлайн: .alk-req на ВМ без сети → портал → .alk-lic → активировано; освобождение файлом.
3. Локальный сервер с исходящим доступом: регистрация, пакет по расписанию, активация, отчёт, квитанция.
4. Изолированный контур: регистрация файлом, пакет файлом, активация, отчёт файлом, импорт отчёта на центральном.
5. Автоосвобождение: сдвиг времени стенда на release_after_days + 1 → released_auto → повторная активация при выходе на связь.
6. Политика: NOTICE → GRACE → RESTRICTED → продление → ACTIVE (откат блока) — со сдвигом времени сервера.
7. monitor: лицензия просрочена, функции не ограничены, сообщения показываются.
8. Триал: 30 дней, переустановка, перевод часов.
9. АльтерОфис Web и АльтерОС — по фикстурам совместимости против стенда.
Каждый тест сам готовит данные через Admin API и удаляет их. Результат — HTML-отчёт с шагами; критерии 15.6 docs/specs/01-architecture.md отмечаются в docs/traceability.md.
```
