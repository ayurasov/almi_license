# I5-02. Нагрузка (E16-05)

```text
История E16-05. Напиши сценарии k6 в tests/load/.

- Данные: набор seed-load (раздел 4 docs/specs/07-environments.md) — 20 000 лицензий, 500 000 активаций; генератор подписанных запросов check заранее готовит ключи устройств (файл с 10 000 активаций и их закрытыми ключами — только для стенда).
- Сценарий check: 100 запросов/с, 15 мин, p95 < 500 мс, ошибки < 0,1 %.
- Сценарий activate: 20 запросов/с, 10 мин, p95 < 500 мс.
- Сценарий конкурентности: 200 виртуальных пользователей одновременно активируют одну лицензию с limit = 100; после теста число активных активаций = 100 + резерв.
- Сбор: метрики k6 + /metrics сервера + pg_stat_statements; отчёт с топ-10 запросов БД по времени.
Если цели не достигнуты — выдай анализ узких мест с предложениями, но не меняй код сервера в этой истории.
```
