## Демонстрация и выход

**Демонстрация I2.** `lm-demo activate <ключ>` на Windows и Linux получает аренду со стенда `test-central`, `lm-demo check` продлевает её; оператор через консоль создаёт заказчика; предпросмотр импорта показывает ошибки синтетической выгрузки; 50 параллельных активаций не превышают лимит.

**Критерии выхода I2.** Все методы Product API, кроме офлайн-файлов, отвечают по контракту (`make contract-check` и контрактные тесты QA); все policy-векторы проходят на сервере; CI зелёный; стенд `test-central` обновляется автоматически.
