# I2-06. Импорт выгрузки ЛК: предпросмотр (E06-01, E06-02)

```text
Истории E06-01 и E06-02. Реализуй licensing.domain.import_lk: parse(file) -> ImportPreview; mapping артикулов.

- Разбор XLSX — openpyxl в режиме read_only; размер файла до 20 МБ, строк до 100 000.
- Колонки и правила — раздел 14.1 docs/specs/02-interaction-spec.md и раздел 8 docs/specs/04-catalog.md. Заголовки ищутся по имени без учёта регистра и пробелов; отсутствие обязательной колонки — ошибка файла.
- Для каждой строки: статус (new / update / skip / error), причина ошибки на русском, распознанные поля; ключ в предпросмотре — только маска.
- ArticleMapping: таблица соответствия AA → product, edition, metric; строка с несопоставленным AA — error с текстом «Артикул не сопоставлен: <AA>».
- Предпросмотр сохраняется как ImportSession (статус draft, срок жизни 24 ч); в лицензии ничего не пишется.
Тесты: на файле tests/fixtures/lk-export-sample.xlsx (синтетический, 30 строк, все виды ошибок); на пустом файле; на файле без колонки «Код лицензии».
```
