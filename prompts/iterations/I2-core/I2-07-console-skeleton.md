# I2-07. Каркас консоли и эталонный экран (E07-01, E07-03)

```text
Истории E07-01 и E07-03. Создай консоль в console/.

E07-01:
- Vite + Vue 3.5 + TypeScript strict + PrimeVue 4 (тема Aura) + Pinia + Vue Router + vue-i18n (ru по умолчанию, en);
- клиент API: openapi-typescript по схеме Admin API (/api/admin/schema), openapi-fetch; генерация командой npm run gen:api; сгенерированный каталог src/api/generated не правится руками;
- макет: боковое меню (Заказчики, Лицензии, Активации, Каталог, Профили, Импорт, Статистика, Журнал, Пользователи), шапка с пользователем и выходом;
- обработка ошибок problem+json: глобальный перехват, toast с user_message, ошибки полей — в формах;
- eslint (vue, typescript), vitest; сборка в образ almi-license-console (Nginx).

E07-03 — эталонный экран «Заказчики»:
- DataTable с серверной пагинацией (lazy), сортировкой и фильтрами (название, ИНН, статус); состояние фильтров в query-параметрах URL;
- форма создания и редактирования в Dialog; валидация zod (ИНН 10 или 12 цифр с контрольной суммой); ошибки сервера по полям;
- пустое состояние, загрузка, ошибка сети;
- хранилище Pinia useCustomersStore с методами list, get, create, update;
- тесты vitest для хранилища и функции проверки ИНН; один сценарий Playwright: создать заказчика и найти его фильтром.

Этот экран — образец. Опиши в console/docs/reference-screen.md, из каких частей он состоит и как по нему делать новые экраны (файлы, имена, хранилище, тесты).
```
