## Демонстрация и выход

**Демонстрация I1.** CI проходит векторы на Python (`tools/vectors`) и C++ (`LeaseVerifier`); `almi-keytool` выпускает сертификат ключа выпуска, `verify` его подтверждает; миграции применяются на стенде `test-central`.

**Критерии выхода I1.** Тег `contract-v1.0.0` поставлен; все policy-векторы проверены техническим лидером; ADR-001…011 в репозитории; фикстуры совместимости записаны; точки встраивания в Desktop согласованы.
