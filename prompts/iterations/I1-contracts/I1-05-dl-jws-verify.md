# I1-05. Проверка JWS в DL (E13-02)

```text
История E13-02. Реализуй LeaseVerifier в sdk/cpp/src/crypto/.

Вход: компактный JWS, список корневых ключей (встроенный по LM_TRUST_ROOTS), список отозванных kid, последний применённый seq, текущее доверенное время.
Выход: результат (valid, код ошибки) и разобранные утверждения.

Порядок проверки (строго):
1. Длина до 64 КБ; три части; строгий base64url без паддинга и лишних символов.
2. Заголовок: alg = EdDSA, typ из допустимого списка; иначе ошибка.
3. Цепочка chain: каждый сертификат проверяется подписью вышестоящего, начиная с корня; роль и срок сертификата; kid не в списке отзыва.
4. Подпись JWS ключом последнего звена — crypto_sign_verify_detached (libsodium).
5. Только после этого — разбор полезной нагрузки (nlohmann/json), проверка ver, aud, nbf, exp, seq > последнего.

Тесты: все векторы contracts/vectors/jws/*.json; тест читает каталог и сравнивает с expected. Секреты и промежуточные буферы обнуляются sodium_memzero.
Ревью технического лидера обязательно (P7, область «DL»).
```
