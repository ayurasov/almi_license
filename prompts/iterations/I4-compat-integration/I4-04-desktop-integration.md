# I4-04. Встраивание модуля в АльтерОфис Desktop (E14-02, E14-03, E14-04)

Промпт выполняется в репозитории продукта; ассистенту передаются заголовок `license_module.h`, разделы 15.2–15.4 документа 2, разделы 3.1, 4, 5, 7 документа 5 и документ точек встраивания из E14-01.

```text
История <E14-02 | E14-03 | E14-04>. Встрой модуль лицензирования в АльтерОфис Desktop по документу точек встраивания docs/licensing-integration.md (результат E14-01).

Правила:
- продукт вызывает только функции LM_* из license_module.h; никакой своей логики сроков и состояний;
- LM_Initialize при старте до создания главного окна; LM_Shutdown при выходе; колбэк изменения состояния обновляет интерфейс в UI-потоке;
- доступность функций — только LM_HasFeature("<функция>") из каталога docs/specs/04-catalog.md раздел 5.1; кэшировать результат не дольше чем до следующего колбэка;
- тексты — из LM_GetMessages; если пусто — встроенные ресурсы с ID из docs/specs/05-messages.md;
- ошибка модуля не должна ронять продукт: любое LM_ERR_* кроме ожидаемых → работа как в UNLICENSED с записью в журнал продукта.

E14-02: диалог активации — элементы и тексты раздела 4.1 документа 5; адрес сервера из настройки.
E14-03: баннер и модальные сообщения по placement и repeat; окно «О программе» — раздел 7 документа 5.
E14-04: неактивные элементы для функций, которых нет в LM_HasFeature, с подсказкой restricted.feature; режим read_only — открытие, печать, экспорт без сохранения.
Для проверки используй заглушку библиотеки (E13-11) с переключением состояний через переменную окружения LM_STUB_STATE.
```
