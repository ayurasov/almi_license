## Демонстрация и выход

**Демонстрация I3.** Оператор выполняет все операции в консоли; офлайн-активация на ВМ без сети через портал; локальный сервер в `test-local` регистрируется онлайн, в `test-airgap` — файлом, и выдаёт аренды `lm-demo`; статистика показывает версии и последний контакт.

**Критерии выхода I3.** Все функции `LM_*` реализованы; `StateEvaluator` и сервер дают одинаковый результат на 100 % векторов; локальный сервер работает в обоих вариантах; заглушка DL передана команде продукта.
