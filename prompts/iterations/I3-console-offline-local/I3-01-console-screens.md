# I3-01. Экран по образцу (E07-04, E07-05, E07-06, E07-07, E07-09)

Один промпт на каждый экран; меняются только поля.

```text
История <ID>. Создай экран «<название>» строго по образцу console/docs/reference-screen.md (экран «Заказчики»).

Данные: эндпоинты Admin API <список operationId>.
Таблица: колонки <список>; фильтры <список>; сортировка по <поля>.
Карточка / форма: поля <список с типами и правилами проверки>.
Действия: <список> — каждое через диалог подтверждения; для «Отозвать» и «Снять блок» обязательна причина.
Тексты — только через i18n, ключи <экран>.<элемент>; русские тексты из docs/specs/05-messages.md, где они есть.
Тесты: vitest для хранилища; Playwright — один основной сценарий.
Не создавай новых общих компонентов; если без нового компонента не обойтись — остановись и объясни (P12).
```

| Экран | История | Данные и действия |
|---|---|---|
| Лицензии | E07-04 | Список с фильтрами продукт, заказчик, статус, срок; карточка: параметры, ключи (маски), активации, история изменений, использование; действия: продлить, приостановить, отозвать, снять блок, monitor/enforce, перевести на другого заказчика (E01-08) |
| Активации | E07-05 | Поиск по `activation_id`, имени, версии; отметки резерва и конфликта; ручное освобождение с причиной |
| Каталог и профили | E07-06 | Продукты, редакции, функции; профили по классам; редактор сообщений с предпросмотром подстановок; история версий профиля |
| Импорт | E07-07 | Мастер из 4 шагов: загрузка, предпросмотр, сопоставление артикулов, подтверждение и отчёт |
| Пользователи консоли | E07-09 | Создание, блокировка, роли, сброс пароля |
