# 12.1. Тестирование

| Задача | Промпт |
|---|---|
| Контрактные тесты метода | «Для operationId=<…> из contracts/openapi-product-api-v1.yaml напиши тесты в tests/contract/: успешный ответ валидируется схемой; каждый код ответа из спецификации метода вызывается и проверяется по схеме Problem; неизвестные поля в запросе не ломают обработку.» |
| Тест-кейсы из критериев | «Преобразуй критерии приёмки истории <ID> в тест-кейсы: предусловия, шаги, ожидаемый результат, тип (авто / ручной), ссылка на критерий 15.6, если применимо. Добавь пограничные и негативные случаи, которых нет в критериях.» |
| Разбор отчёта | «Вот отчёт прогона E2E. Сгруппируй падения по первопричине, отдели нестабильные тесты от дефектов, для каждого дефекта сформулируй описание по шаблону P11.» |
