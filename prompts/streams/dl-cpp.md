# 12.3. Модуль DL

Дополнительные правила для любого промпта по C++:

```text
Дополнительно к AGENTS.md для sdk/cpp:
- исключения не пересекают границу C ABI: каждая функция LM_* оборачивает тело в try/catch и возвращает код;
- никаких глобальных объектов с нетривиальным конструктором; состояние модуля — в одном объекте, создаваемом LM_Initialize;
- строки на границе ABI — UTF-8; на Windows преобразование в UTF-16 только внутри platform/win;
- каждый буфер, содержащий ключ, аренду или сырые компоненты отпечатка, обнуляется sodium_memzero перед освобождением;
- платформенный код только в src/platform/{win,linux}; общий код без #ifdef;
- после изменений: clang-tidy без новых предупреждений, тесты под ASan и UBSan.
```
